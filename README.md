### 系统要求

🤖Android12+

---

#### 功能介绍

1.由MIUIX组件库构建UI

2.支持连接标准Cloudreve V4站点（❌暂不支持V3 | 不会支持V2及以下版本）

3.支持查看站点用户存储的文件，图片，音乐等

4.支持对文件进行上传，下载，删除，复制，分享等操作

5.支持播放音乐，提供专属播放器页面，支持加载歌词（LRC，TTML等歌词格式）

5.支持查看图片，预览图片，图片墙展示，并且图片可查看详细信息与编辑图片

6.支持通过Live Update展示歌词（✔需安卓16及以上版本）
